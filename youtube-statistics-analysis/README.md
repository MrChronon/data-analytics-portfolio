# Global YouTube Statistics Analysis

Итоговая учебная работа по статистике и машинному обучению на датасете **Global YouTube Statistics**.

## Задачи

- провести EDA и изучить структуру данных, пропуски и выбросы;
- сформулировать исследовательские вопросы и визуализировать результаты;
- оценить взаимосвязи между числовыми признаками;
- сравнить корреляции Пирсона и Спирмена;
- построить линейную регрессию для количества подписчиков;
- проверить распределение остатков модели;
- классифицировать каналы категорий `Entertainment` и `Music`;
- сравнить исходный и альтернативный наборы признаков;
- оценить классификацию по `accuracy`, `macro F1-score` и baseline-модели.

## Что доработано после ревью

В итоговую версию добавлены:

- визуализация пропусков с `missingno`;
- точечное восстановление пропусков в логически связанных признаках;
- ранговая корреляция Спирмена для асимметричных распределений;
- диагностика остатков линейной регрессии и Q-Q график;
- `stratify=y` при разбиении данных для классификации;
- `macro F1-score` вместе с accuracy.

## Стек

Python, pandas, Matplotlib, Seaborn, missingno, SciPy, scikit-learn, Jupyter Notebook.
